# CuppyCash - Smart Finance Tracker

CuppyCash adalah aplikasi finance tracker berbasis web untuk mencatat pemasukan, pengeluaran, budget, saving goals, history, chart, profile, serta authorization Admin/User.

## Tech Stack
- Frontend: React.js + Vite
- Backend: Express.js
- Database: MySQL
- Authentication: JWT
- Authorization: Role Admin/User

## Fitur
- Register dan Login
- Dashboard
- Income
- Expense
- Category
- Chart
- Budget
- History
- Saving Goals
- Profile
- Admin Users

```bash
cd backend
